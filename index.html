# Subscription API — Stripe-backed, async-notified
from rest_framework.viewsets import ModelViewSet
from .models       import Subscription
from .tasks        import notify_billing
from .permissions  import IsTenantOwner


class SubscriptionViewSet(ModelViewSet):
    permission_classes = [IsTenantOwner]
    queryset = Subscription.objects.select_related("plan", "tenant")

    def perform_update(self, serializer):
        """Save the change, then dispatch billing async."""
        sub = serializer.save()
        notify_billing.delay(sub.id, event="plan_changed")
        return sub

Celery · SQS · workers

Async pipelines, decoupled from the API.

Long-running work — email, billing, image builds, AI calls — gets handed to workers. Your API stays under 50ms.

  • Decoupled by design. Web tier produces; workers consume; no shared state at the join.
  • Retries with intent. Exponential backoff, dead-letter queues, observable failure modes.
  • Real-world stacks. Celery + Redis, Celery + SQS, or pure SQS workers when latency demands it.
